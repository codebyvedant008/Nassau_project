# 🍬 Nassau Candy Enterprise Analytics Dashboard

> **A Platinum-Level Business Intelligence Suite for Product Profitability & Supply Chain Diagnostics.**

![Dashboard Preview](https://cdn-icons-png.flaticon.com/512/3063/3063822.png)

## 🚀 Overview
This repository contains a high-end, industry-grade analytics platform built for **Nassau Candy Distributor**. Designed to bridge the gap between raw sales data and strategic decision-making, this dashboard provides executive-level insights into product margins, cost leakage, and future revenue projections.

## ✨ Key Features

### 🏢 Executive Intelligence Brief
*   **AI-Powered Narrative**: Automatically generates natural language summaries of current business performance.
*   **Vibrant KPI Cards**: Real-time tracking of Revenue, Profit, and Margin efficiency with glassmorphism aesthetics.

### 💎 Product Profitability Matrix
*   **Quadrant Analysis**: Categorizes the entire portfolio into *Stars*, *Hidden Gems*, *Dangerous*, and *Candidates for Removal*.
*   **Interactive SKU Deep-Dive**: Search any product to see its historical performance trends instantly.

### 🎲 Scenario Simulator (What-If Analysis)
*   **Dynamic Margin Projections**: Real-time sliders to simulate how global price hikes or COGS increases will impact the bottom line.
*   **Export Ready**: One-click CSV export for any simulated scenario or filtered dataset.

### 📉 Cost Diagnostics & Pareto
*   **Pareto (80/20) Rule**: Visualizes which 20% of products are driving 80% of the total profit.
*   **Margin Leakage Alerts**: Automatically flags products where costs exceed revenue thresholds.
*   **Correlation Matrix**: Statistical breakdown of KPI inter-dependencies.

### 🔮 Predictive Revenue Modeling
*   **ML Forecasting**: Uses Linear Regression to project the next 6 months of revenue.
*   **Confidence Intervals**: Shaded uncertainty bands (80% CI) to communicate predictive risk to stakeholders.

### 🏭 Supply Chain Intelligence
*   **Geospatial Mapping**: Interactive Folium-based map visualizing global distribution networks and factory performance.

## 🛠️ Technology Stack
*   **Frontend**: Streamlit (Premium Custom CSS & Glassmorphism)
*   **Analytics**: Pandas, NumPy, Scikit-Learn
*   **Visualization**: Plotly (Custom Theming), Folium
*   **Design**: Google Fonts (Outfit & Inter), SVG Icons

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/codebyvedant008/Nassau_project.git
   cd Nassau_project
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Dashboard:**
   ```bash
   streamlit run app.py
   ```
